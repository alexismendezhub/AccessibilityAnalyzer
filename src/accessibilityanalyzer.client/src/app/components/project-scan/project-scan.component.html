Project / files

Load any kind of project: a folder, individual files, or a ZIP. Every HTML component (.html, .cshtml, .razor, .aspx, .vue, .svelte…) is checked against Section 508 and corrected where that can be done safely. In .ts, .js, .jsx and .tsx files only the markup is corrected (Angular/Vue template: strings and React JSX); the code around it is never changed. C#, Markdown and every other file are never modified; warnings found in them are reported for the developer. Everything stays in your browser except the text sent for analysis.

Folders to skip

Files inside these folders are not loaded: they are not analyzed, not shown in the project structure and not included in the downloads. Changes apply to the next load.
